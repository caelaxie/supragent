# SuprAgent

A repository for organizing and managing different agent skills.

## Structure

- `skills/` - Individual agent skill implementations
- `templates/` - Reusable templates for creating new skills
- `docs/` - Documentation and guides
- `examples/` - Example implementations and usage patterns
- `tests/` - Test suites for skills

## Getting Started

1. Browse existing skills in `skills/`
2. Use templates in `templates/` to create new skills
3. See `examples/` for usage patterns
4. Read `docs/` for detailed guides

## Contributing

Add new skills to the `skills/` directory following the template structure.
